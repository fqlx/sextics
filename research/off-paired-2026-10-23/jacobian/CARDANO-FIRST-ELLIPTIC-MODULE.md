# A finite first-elliptic factor in the Cardano correction

This gives an exact algebraic module and a source-parameter derivative split.
It does not close the auxiliary scalar primitive's parameter derivatives.
`cardano-first-elliptic-module.py` checks eight identities.

On `S³+T³=H` put

```
P=ST, D=S³−T³, K=S²+ST+T²,
delta_E=3T² partial_S−3S² partial_T,
q=−(S+T)/(2K),
N=−3ST(S²−T²)/K².
```

Then the actual first Cardano source obeys the exact finite system

```
delta_E(q)=N,
delta_E(N)=36P*q−3(H²+8P³)/(P D)*N,
delta_E(P)=−3D,
delta_E(D)=18P²,
D²=H²−4P³.
```

Thus `(q,N)` is a closed rank-two differential module over the invariant
field generated by `P,D,H`, on the displayed open. The poles at `P D=0`
are basis/normalization denominators and remain part of the data.

The explicit remaining Y source from the constructive agent factors,
up to its chosen residue-order sign and normalization, into

```
q * D/P² * [C−2B³/(27P³)]/[C+B³/(27P³)]².
```

If an actual source-linear Y scalar construction is obtained, one may
therefore factor its scalar primitive and accompanying Y currents as

```
g=q D/P² * g0(d,X;E2,Y), d=P³,
```

with the same prefactor for the Y currents. The complete first-elliptic
parameter derivative is then

```
delta_E,param g
 =D/P²*N*g0
  +6(H²/P³−1)*q*g0
  −9D²*q*partial_d(g0).
```

The first two terms belong to the explicit `(q,N)` module. The last
contains a genuine parameter derivative of the unknown Y primitive. It
is not set to zero or identified with a polynomial first-Fano source.

Before restricting the two elliptic factors to a diagonal, the second
primitive is a function `g(E2;E1,X)`. The second scalar theorem controls
`delta_2 g`; after diagonal restriction the invariant derivative is
`delta_diag=delta_1,param+delta_2`. Consequently the full residue
contraction has an extra term `Res(f*delta_1,param g)`, in addition to the
X-current cross term in `PARAMETER-DEPENDENT-CONTRACTION.md`.

This finite factor is useful only together with an actual theorem for the
Y boundary source and a compatible primitive-jet closure for `g0`.
