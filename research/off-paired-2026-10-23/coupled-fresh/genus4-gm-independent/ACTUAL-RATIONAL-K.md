# Actual scalar rational remainder and its retained curve defect

This is a constructive scalar identity for the authoritative source
`Ssrc=(D-6)(D-5)h`. It is not a primitive for the original sextic: the
curve-valued defect generated by `(Z-1)K` is retained and still needs serving.
All coefficient fields below have characteristic zero. Identities hold on the
generic dense chart and therefore as identities of rational functions.

## Binding and inputs

The exact source is bound by `corrected-rational-source-binding.json`, SHA256
`d725307869fcf3a2f064a0a6616eee78ea59f74dd3305fcb1d2408d3018f25b5`.
Use only the `actual_Ssrc_residue` table in
`cubic-residue-potentials-results.json`. The separate `h_residue` table is
diagnostic and does not serve this source.

Set

```
u=J/i^2, T=1+w^3, N0=9w^2-16uT, N=i^2*N0,
L=256*T^5*N+729*i^6*J*w^6,
v=64*J*w*N*T^2/(9*i^2*L).
A=partial_i-v_i/v_w*partial_w,
B=partial_J-v_J/v_w*partial_w,
Z=v/v_w*partial_w,
D=6Z-2iA-2JB.
```

These are the actual rational-coordinate derivations, not derivatives with
untransported physical coordinates held fixed. Let `f,g,Crt` be the degree at
most two polynomials in `w` from that authoritative table. Define the actual
rational potentials

```
F=(v^2/v_w)*i^-1*f*N0_w/N0,
G=(v^2/v_w)*g*N0_w/N0,
t=i^-6*w*T*L*Crt,
Hpot=v*t.
```

The scalar operators are

```
PE=(D-6)(D-5)+A(Z+D/2-2),
PD=4JB^2+2B+A(Z+JB),
P3=A^3+v(Z+JB+1)Z(Z+D/2+1).
```

Operator products act from right to left. The assertion constructed below is

```
Ssrc-PE(F)-PD(G)-P3(Hpot)=(Z-1)K.                 (1)
```

## Literal Cartan correction, including every fold pole

For a scalar `Q`, write `alpha(Q)=Q*v_w/v^2*dw`. Parameter partials in this
section hold `w` fixed. Direct differentiation gives the literal identities

```
alpha(AQ)=partial_i alpha(Q)+d_w EA(Q), EA(Q)=-Q*v_i/v^2,
alpha(BQ)=partial_J alpha(Q)+d_w EB(Q), EB(Q)=-Q*v_J/v^2,
alpha(ZQ)=alpha(Q)+d_w EZ(Q),          EZ(Q)=Q/v.
```

Put

```
Dbar=6-2i*partial_i-2J*partial_J,
ED(Q)=6EZ(Q)-2iEA(Q)-2JEB(Q),
L0=Z+D/2-2, EL(Q)=EZ(Q)+ED(Q)/2,
M0=Z+JB,    EM(Q)=EZ(Q)+J*EB(Q).
```

Thus `alpha(DQ)=Dbar alpha(Q)+d_w ED(Q)`. For any product of the listed
operators the exact correction is obtained recursively from
`E_MN(Q)=barM E_N(Q)+E_M(NQ)`. Coefficients used here depend only on `i,J`,
so parameter operators commute with `d_w`. In particular the full corrections
needed for (1) are

```
ES(h)=(Dbar-6)ED(h)+ED((D-5)h),
EPE(F)=(Dbar-6)ED(F)+ED((D-5)F)
       +partial_i EL(F)+EA(L0 F),
EPD(G)=4J*(partial_J EB(G)+EB(BG))+2EB(G)
       +partial_i EM(G)+EA(M0 G),
EA3(Q)=partial_i^2 EA(Q)+partial_i EA(AQ)+EA(A^2Q).
```

No pole is removed from these corrections. In particular poles at `v_w=0`,
which occur in `F,G`, remain in `EPE,EPD` and therefore in `K`.

The following identity is literal, using the commuting `A,B,Z` and `Zv=v`:

```
P3(v*t)=v*A^3t+(Z-1)W(t),
W(t)=v^2*(Z+JB+2)*(Z+D/2+5)t.
```

Since `Av=0`,

```
alpha(P3(v*t))=partial_i^3(t*v_w/v)*dw
               +d_w[EA3(v*t)+W(t)/v].
```

Consequently the full actual left side of (1), after applying `alpha`, is

```
RN*dw+d_w Ctot,
Ctot=ES(h)-EPE(F)-EPD(G)-EA3(v*t)-W(t)/v,          (2)
RN=(Dbar-6)(Dbar-5)ah
   -[(Dbar-6)(Dbar-5)+partial_i(Dbar/2-1)]aF
   -[4J*partial_J^2+2partial_J+partial_i(1+Jpartial_J)]aG
   -partial_i^3 at,
ah=54*i^3*w*T/(J*N), aF=i^-1*f*N0_w/N0,
aG=g*N0_w/N0, at=t*v_w/v.
```

These equations restore the full differentiated potentials; they do not
replace them by their residues.

## Why no omitted finite residue remains

The three initial forms `ah dw,aF dw,aG dw` have finite poles only at `N0=0`.
The fourth satisfies the explicit rational identity

```
at=i^-6*Crt*(T*L+2w*L*T_w-w*T*L_w+w*T*L*N0_w/N0).
```

Here `L` is polynomial in `w`; hence `at dw` also has finite poles only at
`N0=0`. Parameter differentiation at fixed `w` preserves that property.
Thus `RN dw` has no poles at `w=0`, `T=0`, `L=0`, or at the critical points
`v_w=0`. Every such pole in the original full remainder is contained in the
explicit exact term `d_w Ctot`. In particular its residue is zero, with all
its principal parts retained in (2).

At `N0=0`, the actual physical residue has the factor `i^-1`. The
`actual_Ssrc_residue` table uses
`rTarget=4u^2*r_h''+14u*r_h'+6r_h`, with the cubic Gauss--Manin derivative.
The exact RIGHT Ore identity `L1*U+L2*V=1` proves cancellation of that actual
residue. This source and scaling are bound by the hash above. Independent
complete rational Hermite reduction, described next, checks cancellation
again after every parameter differentiation; it does not assume residue
cancellation from a degree count. The residue at infinity then vanishes by
the rational residue theorem. Higher principal parts at infinity remain.

## Explicit rational primitive of RN

The exact data file
`../ruling-source/adjoint-reconstruction/n-only-hermite-results.json`
contains the primitive in three independent Laurent weights:

```
PN=i^-1*P1(u,w)+i^-2*P2(u,w)+i^-7*P7(u,w),
d_w PN=RN*dw.
```

Each `Pj` is the polynomial with low-to-high coefficients in
`polynomial_primitive_coefficients`, plus the sum of
`numerator_coefficients/N0^denominator_power` from its
`proper_primitive_terms`. The three labels are `i^-1,i^-2,i^-7`.
`construct_n_only_hermite.py` verifies, with exact `QQ(u)[w]` arithmetic,
both zero simple-pole remainder and the complete derivative identity in
each weight. It performs no truncated or numerical substitution.

For a compact alternative to this coefficient file, divide `RN` into a
polynomial `Q` and `P/q^4`, with `q=w^3-9w^2/(16u)+1`, `deg(P)<12`.
Let `M[k,j]=[w^k](q*(w^j)'-3q'*w^j)`, `0<=k,j<=8`.
Its determinant is exactly `-362880`. Put
`Uvec=adj(M)*(P0,...,P8)^t/(-362880)` and `U(w)=sum(Uvec[j]w^j)`.
The complete zero-residue checks imply
`q U'-3q'U=P`, including coefficients 9,10,11; these coefficients are
constraints, not equations silently discarded by the square solve.
Then `PN=integral(Q)dw+U/q^3`. This is the same primitive up to a
parameter-only integration constant.

## Constructed K and remaining obligation

Combining (2) with the checked primitive gives the explicit compressed
rational function

```
K=v*(PN+Ctot).                                      (3)
```

Indeed `alpha((Z-1)K)=d_w(K/v)`, so (2)--(3) prove (1), including the
fixed poles, critical poles, all higher orders, and infinity. The formula
uses only differentiation, finite polynomial coefficient arrays, and
rational arithmetic; it does not invoke an unevaluated integral or a
formal existence of a primitive.

The original curve section is still present: the constructed right side
`(Z-1)K` produces a coupled curve-valued source. The compact
`OmegaTheta` correction and its infinity companion must serve that
source before this can become a certificate for the sextic.

## Source-specific integration normalization

There is an explicit useful choice of the integration freedom
`K -> K+v*C(i,J)`. Set

```
c1(u)=P1(u,0), c2(u)=P2(u,0), P7(u,0)=0,
Kreg=K-v*[i^-1*c1(u)+i^-2*c2(u)].
```

The exact factored rational arrays `c1,c2` are saved in
`actual-rational-k-normalization.json`; they are evaluated from the
authoritative complete primitive, not fitted from sample values.

At `w=0` the actual vector fields have the expansions

```
v=(u/36)w+O(w^2), v_i/v_w=-(2/i)w+O(w^2),
v_J/v_w=w/(i^2*u)+O(w^2), v/v_w=w+O(w^2).
```

Thus `A,B,Z,D` preserve every nonnegative `w`-adic order. In particular
this order statement is checked for the actual physical derivations, not
assumed from partial differentiation at fixed `v`. Each of
`EA,EB,EZ,ED` lowers order by at most one. The actual inputs have
`h,F,G=O(w^3)`, `t=O(w)`, `v*t=O(w^2)`. The corrections in (2) therefore
satisfy `ES,EPE,EPD=O(w^2)`, `EA3(v*t)=O(w)`, and `W(t)/v=O(w^2)`.
Consequently `Ctot(0)=0` and the displayed subtraction removes exactly
the constant term of `K/v`.

It follows that `Kreg=O(w^2)` and `(D-7)Kreg=O(w^2)`. On the retained
coefficient cover `e^6=v`, the actual weighted coefficients improve to

```
e^-7*Kreg=O(e^5),
e^-8*(D-7)Kreg=O(e^4).
```

The scalar identity (1) is unchanged because `(Z-1)(v*C)=0`. The
curve-valued defect is changed by the explicit retained quantity

```
(D-7)(v*C)=v*(D-1)C,
(D-1)C=-i^-1*(2theta+1)c1-i^-2*(2theta+3)c2,
theta=u*partial_u.
```

This is a normalization of the actual source-carrying construction and
removes its `w=0` coefficient pole. It does not cancel a compact or
infinity row. `normalize_actual_rational_k.py` checks the expansions
and exact primitive constants.
