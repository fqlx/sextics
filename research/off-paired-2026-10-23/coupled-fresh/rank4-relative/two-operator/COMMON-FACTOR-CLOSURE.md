# A positive rational common-factor closure for Lhat and Y

This constructs rational differential-operator identities, not a primitive of
the actual forcing. It uses a fixed 15-dimensional operator space and an exact
positive nonzero-minor certificate. It is not a denominator or degree search.

Keep the actual physical H(a,C,z), and write

    Y=H_z partial_a−H_a partial_z,
    D_H=(1/H_a)partial_a,
    D_C=delta−(h/H_a)partial_a,
    E=D_z|H,C=partial_z−(H_z/H_a)partial_a=−Y/H_a,
    h=delta H, delta=partial_C|a,z.

The three derivations D_H,D_C,E commute. The following discussion concerns
rational differential operators on the actual coefficient field; a and its
physical derivatives are retained.

Let V be the 15-dimensional vector space over that field with ordered basis

    1;
    D_C,D_H;
    D_C^2,D_HD_C,D_H^2;
    D_C^3,D_HD_C^2,D_H^2D_C,D_H^3;
    D_C^4,D_HD_C^3,D_H^2D_C^2,D_H^3D_C,D_H^4.

Map an operator in V to its action on omega0 in the compact rank-four module.
The image matrix has rank four because 1,D_C,D_C^2,D_C^3 are cyclic. Its
kernel therefore has dimension eleven. Both the universal Euler operator

    A_univ=3H D_H+2C D_C+2

and the universal compact Picard–Fuchs operator L_C are in this kernel.

## Eleven explicit kernel rows

Expand the actual bare monic operator Lhat_delta in this ordered basis,
using delta=D_C+h D_H. Let v0 be its coefficient row. Define

    vk=E^k(v0), k=0,...,10,

where E differentiates coefficients only. All vk remain in the kernel,
because the universal image matrix depends only on H,C and E(H)=E(C)=0.

The rows vk are actual rational functions. They can be generated without
symbolic expansion by the following finite recurrences:

1. Build all fifteen images D_H^iD_C^j omega0 from the supplied universal
   matrices, through total order four.
2. Expand delta^n recursively for n=0,...,4. For each coefficient b,
   delta(b)=partial_C b+h0 partial_H b
             +sum h_(i+1) partial_(h_i)b.

   The bare delta-power expansion coefficients themselves depend only on
   the h_i, so their first two terms are zero. Here

       h0=18q^5/a^2+3z/2,
       h1=270q^4/a^2,
       h2=3240q^3/a^2,
       h3=29160q^2/a^2.

3. Reduce those five delta columns through the universal image matrix and
   solve the cyclic 4x4 system for the four monic Lhat coefficients.
4. Differentiate the resulting rational coefficient row with E.

The exact positive certificate uses

    (a,C,z,H)=(1,1,1,969/64), prime=1009.

All rational denominators used in the specified recurrence are units modulo
1009. The first eleven coefficient columns of the rows v0,...,v10 have

    determinant =383 modulo 1009.

The universal cyclic four-column image minor is 249 modulo 1009. All saved
coefficient rows map to zero modulo 1009. Hence the global rational 11-minor
is nonzero, and the eleven vk span the entire kernel over the actual rational
coefficient field.

## Explicit determinant reconstruction

Let B be the 11x15 matrix with rows vk, and J={0,...,10}. Its square minor
B_J is nonzero. For either q=A_univ or q=L_C, let q_J denote its first eleven
coefficients. Define the actual rational row

    lambda(q)=q_J B_J^(-1).

The inverse may equivalently be written adj(B_J)/det(B_J); this is a concrete
rational formula in the finitely specified recurrences. Kernel dimension
then gives the exact coefficient identity

    q=sum_(k=0)^10 lambda_k(q) Qk,
    Qk=ad_E^k(Lhat_delta).

Because E commutes with D_H,D_C, Qk has precisely coefficient row vk. Also

    Qk=E^k Lhat_delta+Sk E,
    Sk=sum_(r=1)^k (−1)^r binom(k,r)
          E^(k−r) Lhat_delta E^(r−1).

Thus both operators have explicit common-factor representations

    q=R_q Lhat_delta+S_q E,
    R_q=sum lambda_k E^k,
    S_q=sum lambda_k Sk.

Finally E=(−1/H_a)Y, so

    q=R_q Lhat_delta+[S_q composed with multiplication(−1/H_a)]Y.

In particular the parent's bare first-order annihilator

    A=N partial_a+2C H_a delta+2H_a,
    N=3H−2Ch,

is H_a A_univ and therefore belongs to the left ideal generated by
Lhat_delta and Y, with explicit rational determinant coefficients. The
second horizontal annihilator follows from

    Z=(H_z/H_a)A−(N/H_a)Y.

No compact component is omitted: the construction uses the full four-row
image matrix, not just a selected scalar period.

## What this supplies and what remains

Taking ordinary formal adjoints in bare da dC dz transports arbitrary
A*- or Z*-source terms into explicit Lhat_delta* and Y-current terms. For
example, if A=R_A Lhat+S_A Y, then

    A*F=Lhat*R_A*F−Y(S_A*F),

since Y has zero ordinary divergence. The same applies to Z and to L_C.
This is a constructive common-factor/telescoper mechanism with actual
horizontal coupling.

It does not establish that the actual forcing

    D0=partial_a U0+partial_z W0

is in that adjoint image. The task

    Lhat_delta*G=D0+Y(S)

still requires its source-specific integration. No G,S solving that forcing,
finite certificate, or Lean proof is asserted.

`common_factor_rank.py` generates the physical implicit E-jets and all saved
rows. `verify_common_factor_rank.py` independently checks the recorded exact
minor and kernel products using only the Python standard library. The full
finite-field data are in `common-factor-rank-results.json`.
