# Exact finite operator closure retaining the physical source

These formulas use the actual cubic-ray residue `R=Bp/g^3`, where
`g=B+3Cp^2` and `Cp^3+Bp+H=0`. Constants may lie in any fixed field `k` of
characteristic zero; use `k=C` for the full contract. Rational matrix entries
and modular tests over `Q` do not descend arbitrary complex solutions to `Q`.

## A one-variable finite connection

Put

```
kappa=B^3/(C*H^2), F=-H/(p*g), V=F-1/3, W=C*H*R.
```

The finite cubic field is generated by `F`, whose polynomial is

```
(4*kappa+27)*F^3-(4*kappa+27)*F^2+9*F-1=0.
```

Here `Tr(F)=1`, and both `V,W` have trace zero. With
`theta=kappa*d_kappa`, the exact connection is

```
theta(V)=-2W,
theta(W)=3V/(4*kappa+27)+(27-2*kappa)W/(4*kappa+27).
```

Equivalently `V` satisfies the finite-monodromy scalar equation

```
(4*kappa+27)*theta^2(V)-(27-2*kappa)*theta(V)+6V=0.
```

In the previous basis `(p,p^2+2B/(3C))`, the `V` column is
`(-6BCH/D,4B^2C/D)` and the `W` column is `CH` times the previous source
column, with `D=4B^3+27CH^2`. This gauge has determinant
`2B^3C^2H/D^2`; it is a basis on a dense open set.

For rational physical vector currents `A,Bvec` in the `V,W` components, the
complete rank-two current equation becomes

```
div(A)+3/(4*kappa+27)*Bvec(log(kappa))=0,
div(Bvec)-2*A(log(kappa))
 +(27-2*kappa)/(4*kappa+27)*Bvec(log(kappa))=1/(C*H).
```

Use divergence for the actual volume: ordinary divergence in the original
cubic-ray chart `(x,a,u,v)`, or weighted divergence for the full diagonal
quotient. The source remains the second component `1/(CH)` and is not
replaced by a constant.

The identity `dF=-2CH R dlog(kappa)` gives the closed-time criterion. For an
actual rational symplectic form `omega` with `omega^2/2=Omega`, a closed
rational one-form `eta` satisfying

```
eta(Z)=1,
Z=CH*X_log(kappa)=3CH/B*X_B-H*X_C-2C*X_H
```

would give the actual closed two-form `beta=-dF wedge eta/2` with
`beta wedge omega=R Omega`. If `omega=d(theta_form)`, the rational
three-form `theta_form wedge beta` would be a primitive. No such `eta`
has been found. This is sufficient, not necessary for the complete
two-component current equation.

Absolute closedness of `eta` can be weakened to `d(kappa) wedge d(eta)=0`.
For example, `eta=sum_j f_j(kappa)*eta_j` has this property whenever the
`eta_j` are closed and the coefficients are arbitrary rational functions
of `kappa`. Indeed `dF` is proportional to `d(kappa)`, so `d(beta)=0`
still holds. This is a larger constructive space than constant combinations.

An alternative sufficient target uses the full divergence equation directly:
find a rational base vector field `A` such that

```
div_Omega(A)=0, A(log(kappa))=-1/(2*C*H).
```

Then `(F-1/3)*A` is an actual trace-zero source current, since its divergence
is `A(F)=R`. All three coefficients `H,B,C` may vary. In the original
volume this is equivalently

```
div(A)=0,
(3HC*dB-BH*dC-2BC*dH)(A)=-B/2.
```

These pure-component and closed-time restrictions have now been excluded
with arbitrary poles, including finite extensions, by the proper Fermat
moment in `PURE-COMPONENT-SCOPE.md`. They must not be used as open positive
targets. This does not exclude the complete coupled current displayed
above or arbitrary closed two-forms.

## CM monomial recurrences with all coefficient derivatives

For the original cubic-ray chart, set

```
H=1+x^6+a^6, C=1+u^6+v^6,
B=b1+b2+b3,
b1=x*u/2, b2=x^3*a*u*v/2, b3=x*a*v/3,
omega0=dx wedge da+du wedge dv.
```

The commuting actual Hamiltonian fields `X_H,X_C` preserve the volume and
satisfy `{H,C}=0`. Write `J={H,B}` and `L={C,B}`. For any integral `r,s`
and any rational cubic-field function `Q(H,B,C,p)`,

```
X_H(x^(r+1)*a^(s+1)*Q)
 =6*x^r*a^s*((r+s+2)*x^6-(r+1)*(H-1))*Q
  +x^(r+1)*a^(s+1)*J*partial_B(Q),

X_C(u^(r+1)*v^(s+1)*Q)
 =6*u^r*v^s*((r+s+2)*u^6-(r+1)*(C-1))*Q
  +u^(r+1)*v^(s+1)*L*partial_B(Q).
```

The last terms must be retained. In particular `Q=p_B=-p/g` has

```
partial_H(p_B)=-p_B/(3H)-4B R/(3H),
partial_B(p_B)=2R,
partial_C(p_B)=-2p_B/(3C)-2B R/(3C).
```

Thus each recurrence is an actual source-carrying current identity with
the explicit remaining `p_B` term. It does not remove the factors `J,L`
from the source without further rational current corrections. Dividing
them out introduces coefficient derivatives and returns the physical
density problem.

`kappa_operator_closure.py` checks 25 exact identities, including all
three gauge-transformed connection matrices, the actual source, the
finite-field polynomial derivation, and the `p_B` relations. No scalar
closed-time solution or primitive is asserted.

## Focused constructive attempts

`closed_form_closure.py` tested 195 canonical closed rational two-forms
in the full diagonal quotient, including rational differentials and
logarithmic differentials. It included the trace-free projection of each
form, which remains closed. The constant-coefficient sampled system was
inconsistent modulo 1009 (207 points, rank 146). The later function `F`
was not part of this family.

`original_closed_time.py` tested 30 canonical `df,dlog(f)` time forms in
the original symplectic chart, including `xa,uv,b1,b2,b3,HC`. Its sampled
system was inconsistent modulo 1009 (45 points, rank 20). No further
degree family was tested. Both results are limited modular feedback,
not proofs of nonexistence over the contract's constant field.

`relative_time_module.py` considered the larger canonical module with
arbitrary coefficients in `k(kappa)`, using the full cubic `t` algebra on
each generic kappa fiber. After exact generator relations it has 22
canonical `df,dlog(f)` generators. At `kappa=1` modulo 1009 its matrix has
rank 22 and its augmentation has rank 23. The saved result includes a
nonzero 23-by-23 augmented minor, which rejects this particular module
without a degree bound on the rational kappa coefficients. This does not
cover arbitrary relative one-forms or the full vector-current equation.

## Actual density on the fixed Fermat cover in the new gauge

On the finite cover `alpha^6=H-1`, `beta^6=C-1`, normalize
`x=alpha*xi,a=alpha*eta,u=beta*nu,v=beta*varpi`, with the two fixed Fermat
curves `xi^6+eta^6=nu^6+varpi^6=1`. The actual source becomes

```
-W *alpha*dalpha/(1+alpha^6) wedge beta*dbeta/(1+beta^6)
   wedge dxi/eta^5 wedge dnu/varpi^5.
```

Both rational one-forms in `alpha,beta` are explicit sums of logarithmic
differentials after adjoining constants: writing `r=alpha^2`,
`alpha*dalpha/(1+alpha^6)=dr/(2*(1+r^3))`. The coupling remains

```
B=alpha*beta*xi*nu/2
 +alpha^4*beta^2*xi^3*eta*nu*varpi/2
 +alpha^2*beta*xi*eta*varpi/3.
```

In particular the different `(alpha,beta)` weights still enter `kappa`
and `W`; the density cannot be integrated as if those factors were
constant. No CM contraction or primitive follows from this rewriting.

## Rational geometric S3 cover of kappa

The normalized b-line Galois cover is elliptic, but the kappa-line
geometric Galois cover is rational. In the full Fermat incidence
`S^3+T^3=H`, `B+3cST=0`, `c^3=C`, use `q=S/T`. Then

```
kappa=-27*q^3/(1+q^3)^2,
F=(q^2-q+1)/(3*(q^2+q+1)),
V=-2q/(3*(q^2+q+1)),
W=q*(q+1)^2*(q^2-q+1)/(9*(q^2+q+1)^3),
p=3Hq/(B*(q^2-q+1)).
```

Over a constant field containing `zeta3`, the maps `q -> zeta3*q` and
`q -> 1/q` generate S3 and fix kappa. Inversion fixes F,W and the
cyclic traces of V,W vanish. Its branch signature is `(3,2,2)`.
The deck description is geometric, for example over `k=C`; the rational
formula over Q does not claim that `Q(q)/Q(kappa)` is already Galois.

`rational_kappa_cover.py` checks 13 exact identities, including the actual
cubic equation, source binding, and the full connection in this cover.
The physical density is still pulled back from the four-base field and
is not constant in q by assumption. A universal rational primitive in q
would not itself settle the physical coupled-current problem.
